# Feedback Log

Use this file to accumulate editing judgments. Keep entries short and specific.

## Entry Format

```text
## YYYY-MM-DD - Manuscript or section

- Change: original phrase -> proposed phrase
- Layer: architecture / language / bridge
- Verdict: accepted / rejected / accepted with revision
- Reason: why it worked or damaged the voice
- Profile update: none / anchor added / anti-anchor added / constraint updated
```

## Rules

- Do not add long excerpts; a phrase or sentence is enough.
- If an edit is rejected, record what the author preferred instead.
- If the same edit type is rejected three times, add a hard veto to `style-profile.md`.
- Update the profile after each session, not only when asked.
